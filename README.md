# TilltheFangz_2.0
Este projeto é uma refatoração de um projeto antigo em node, html, css e js. O objetivo é melhorar a estrutura do código, otimizar o desempenho e adicionar novas funcionalidades.
Hoje o projeto está em desenvolvimento e ainda não possui uma versão estável. No entanto, você pode acompanhar o progresso e contribuir com sugestões ou melhorias.
Infraestrutura do projeto
O projeto utiliza as seguintes tecnologias e ferramentas:
- Java 21
- Spring Boot
- Maven
- MySQL
- Lombok
- JUnit
- Swagger
- Arquitetura hexagonal
Funcionalidades
O projeto possui as seguintes funcionalidades:
- Cadastro de usuários
- Autenticação e autorização
- Criação de personagens
- Listagem de personagens
- Edição e exclusão de personagens
